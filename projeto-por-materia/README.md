# Projeto por matéria

Este é um projeto novo, pensado para crescer uma matéria por vez.

## Estrutura

- `index.html`: painel inicial com as matérias disponíveis
- `styles.css`: estilos compartilhados
- `materias/ciencias/`: primeira matéria pronta
- `materias/ciencias/index.html`: página da matéria
- `materias/ciencias/style.css`: estilos da matéria
- `materias/ciencias/app.js`: lógica do jogo

## Como usar

1. Abra `index.html` no navegador.
2. Escolha a matéria disponível.
3. Quando quiser adicionar outra disciplina, crie uma nova pasta em `materias/` com sua própria página e lógica.
